# M3 Non-destructive: spec

Milestone text and gates: `docs/PLAN.md` sections 4 and 5. Behavior and look come from the reference
app (rules in PLAN.md section 0) and the public Photoshop user guide. Everything here is written in
our own words; option names are the common industry terms. Where the reference app differs from the
PLAN wording, the reference wins; the quirks we follow on purpose are listed in section 9.

Status: draft for owner review. (D) items need an owner decision, section 12 gaps a reading, before their batch.

## 0. Out of M3 scope (named so nobody builds them by accident)

- The 86 filter commands, filter gallery, liquify, puppet warp and perspective warp: M5. M3 smart
  filters host only what M3 ships (D8); M5 filters plug into the same stack.
- Stack mode rendering (entropy, median, ...): stored and round-tripped only (D11); rendering is M6.
- Shape layers, vector masks, type layers and artboards: M4. Fill layers here have no vector path.
- CMYK/Lab/grayscale behavior of adjustments: M6. M3 works on RGB 8/16-bit documents; kinds that need
  three color channels are identity on fewer channels (reference behavior, kept for M6).
- Actions and scripting descriptors (the 4-char aliases of adjustments): M8.
- Style presets library management (preset manager): M9. M3 ships the Styles page and New Style.

## 1. Document model and format (engine)

**Node kinds.** `Kind` in `engine/src/doc.rs` gains three variants next to `Pixel` and `Group`:
- `Adjustment { kind, params }`: no pixels. `kind` is one of the 16 layer kinds of section 3.
- `Fill { content }`: no pixels. `content` is `solid { color }`, `gradient { gradient, style, angle,
  scale, reverse, dither, align_with_layer, offset }` or `pattern { pattern_id, scale, angle, linked,
  offset }`.
- `Smart { link, source, source_size, transform, warp, filters, stack_mask, stack_mode, cache }`:
  `cache` is ordinary pixel tiles in document space (so the compositor treats it like a pixel layer);
  the rest is described in section 6.
Every `Node` gains `style: Option<Style>` (section 5) and `blending: Blending` (blend-if ranges,
channels, knockout, the four group/mask flags). The document gains `global_light { angle, altitude }`
(default 120 / 30), `patterns` and `layer_comps`.

Rules: paint, fill, transform and filter ops on an adjustment or fill layer refuse with an error
that names the layer kind; masks, opacity, blend, clipping, locks and visibility work on every kind.
Adjustment and fill layers have unbounded extent: their mask bounds them (a missing mask = everywhere).
Adjustment layers refuse layer styles; fill and smart layers accept them.

(D1) **Manifest v4 in one bump.** All M3 fields land in B1 so the format changes once: new `kind`
values `adjustment`, `fill`, `smart`; per node `style`, `blending`; document `global_light`,
`patterns`, `layer_comps`. Params are stored as typed JSON (not a raw PSD object); unknown params keys
from a newer file are an error, not silently dropped. The reader keeps accepting v1 to v3.
Persistence change: independent review gate.

(D2) **Blobs share the tile id space.** Smart object sources, pattern pixels and color lookup tables
are immutable byte blobs with copy-on-write ids from the same counter as tiles. The manifest lists
them; `tileIds()` in `app/src/project.ts` collects them, so the `.pbaer` container (u32 version 1)
and the OPFS autosave keep their layout and write each blob once. No container bump.

(D3) **Patterns are per document.** Pattern fill layers, pattern overlays, stroke pattern fills and
bevel texture reference `patterns[id]` in the document (pixels in a blob). Using a preset pattern
copies it into the document; a missing id refuses the op. The IndexedDB library stays the preset
source. PSD export writes the referenced patterns into the `Patt` block; import fills the table.

## 2. Compositor

The draw program (`docs/M1.md` section 3) is the single description of a tile's composite; the CPU
path (`run_program` in doc.rs) and the WGSL path (`app/src/render/composite.wgsl.ts`) execute it.
Program version 2 (`decodeProgram` in `app/src/render/program.ts` refuses version 1 then) adds:

- **`Adjust`** (D4): modifies the backdrop at the top of the stack in place. Payload: opcode, a
  float parameter block and optional tables (1D per channel, or a 3D lookup). Per pixel on straight
  color `o = C / a` (skip when `a <= 0`): compute `j = adjust(o)`; non-normal mode:
  `r = blend(mode, o, j)` with the original as backdrop and the adjusted color as source, else
  `r = j`; `k = opacity * mask * clipAlpha`; `L = o + (r - o) * k`; then blend-if as a second mix
  with "This Layer" read from `L` (not `j`) and "Underlying Layer" from `o`: `w = blendIf(L, o)`,
  `o' = o + (L - o) * w`; write back `o' * a`. Alpha is never changed. Dissolve turns `k` into 0 or
  1 by the M1 dissolve hash.
  Unclipped: applies to everything below it in its group. Clipped: applies to the clip group's
  composited base with `clipAlpha` = base alpha.
- **`Knockout`**: `destAlpha *= 1 - shape * layerOpacity` before the layer's planes are drawn.
  There is no background-layer stop: it punches to transparent. An isolated group bounds it to the
  group's buffer; a pass-through group passes it to the parent buffer. It runs only on a layer with
  at least one enabled effect, and a styled clipping base drops its knockout.
- **Blend-if** on `Draw`: the source alpha is multiplied by the blend-if weight (section 5).
- Fill layers: the engine renders the fill content for the requested tile (solid, gradient via
  `engine/src/gradient.rs`, pattern tiling via `engine/src/pattern.rs`) as a transient payload tile,
  then the ordinary `Draw` step composites it. No cached pixels; the cache key is the content JSON.
  A level tile samples each pixel at its centre in document px (no box average).

Binary layout v2 (replaces the 32-byte step of `docs/M1.md`): 72-byte step records: `u8 op, u8
mask_kind, u8 mode, u8 flags, u32 node, f32 scale, f32 mask_const, u64 src, u64 mask, u32 opcode,
u32 0`, then blend-if bytes (gray, red, green, blue; each source then destination `[black outer,
black inner, white inner, white outer]`). Ops 11 `Adjust` (top buffer in place; `scale` = opacity x
fill; flags bit 0 = clipped, `k *= top shape`; `src` = the payload key of its data block, 0 = none)
and 12 `Knockout` (`src` a tile: punch the top; `src` 0: a group's composite on top punches the
buffer below it; `scale` = layer opacity). Payloads: u64 key, u32 kind (0 RGBA8 tile, 1 mask8 tile,
2 `Adjust` data as an f32 LE array), u32 byte length, bytes; tiles first, then data. A data key is a
`mix` of the data bits with the top bit set, and `known` leaves it out like a tile. `Adjust` opcodes
are the `OP_*` constants of `engine/src/adjust.rs` (1 invert, 2 table, 3 vibrance, 4 hue/saturation,
5 color balance, 6 black & white, 7 photo filter, 8 channel mixer, 9 selective color, 10 gradient
map, 11 3D color lookup), each documenting its data layout; a kind whose params are neutral or
whose table fails to parse emits no step. Dither hashes are `dissolve_hash(x, y, 0)` on document
px. Default blend-if ranges weigh exactly 1.
- Styled layers: the engine renders the effect planes and the styled content per tile (section 5)
  as payload tiles; the program draws them with the existing `Draw` op (mode, opacity) plus
  `Knockout`. The GPU never computes a blur or a distance field.

Tables: 65536 entries per channel for the compositor (reference), sampled with linear interpolation
between entries unless the kind is stepwise (posterize, threshold, pencil curves: nearest entry).
Every kind short-circuits to no step when its params are neutral.

## 3. Adjustments

**Catalogue.** 16 layer kinds, in this order everywhere (menu, panel, PSD mapping): brightness/
contrast, levels, curves, exposure, vibrance, hue/saturation, color balance, black & white, photo
filter, channel mixer, color lookup | invert, posterize, threshold, gradient map, selective color.
Destructive only: shadows/highlights, HDR toning, desaturate, match color, replace color, equalize,
auto tone, auto contrast, auto color. Image > Adjustments lists the first 22 in that order with
separators after color lookup, selective color and HDR toning; the three autos sit in Image.
Shortcuts: Levels Ctrl+L, Curves Ctrl+M, Hue/Saturation Ctrl+U, Color Balance Ctrl+B, Black & White
Ctrl+Alt+Shift+B, Invert Ctrl+I, Desaturate Ctrl+Shift+U, Auto Tone Ctrl+Shift+L, Auto Contrast
Ctrl+Alt+Shift+L, Auto Color Ctrl+Shift+B. New Adjustment Layer has no shortcuts.

**Shared math** (floats 0..1, results clamped): Lum = 0.3r + 0.59g + 0.11b; SetLum adds
`L - Lum(c)` to every channel then clips toward L so min >= 0 and max <= 1. HSL standard, hue in
degrees mod 360. `sat(s, g)`: g = 0 -> s; g < 0 -> s(1 + g/100); g >= 100 -> 1; else s / (1 - g/100).
`light(l, g)`: g < 0 -> l(1 + g/100); else l + (1 - l)g/100. sRGB transfer with the 0.04045 /
0.0031308 knees, exponent 2.4.

**Per kind** (range, default; algorithm; PSD key via ag-psd's `adjustment` object):
1. Brightness/Contrast: brightness -150..150 (legacy -100..100), contrast -50..100 (legacy
   -100..100), legacy off, mean 127 fixed. Modern: `B = b/150`, `x^(1/(1+2B))` for B >= 0 else
   `x^(1-2B)`; c > 0: `k = 1 + 3c/100`, S-curve around `m = 127/255` (`m(x/m)^k` below m, mirrored
   above); c < 0: `m + (x - m)(1 + c/100)`. Legacy: `x + b/200`, then `(x - 0.5)f + 0.5`,
   `f = 1/(1 - c/100)` for c >= 0 else `1 + c/100`. Table. PSD `brit` (import sets legacy) + `CgEd`.
2. Levels: per record input black/white 0..255, gamma 0.01..9.99, output black/white; composite plus
   optional R, G, B records. `v = clamp((x - ib)/(iw - ib))` (step at ib when iw <= ib),
   `v^(1/gamma)`, `ob + v(ow - ob)`. Channel record first, then composite. PSD `levl`.
3. Curves: points 0..255, default (0,0),(255,255); mode point or pencil. Clamp, sort, collapse equal
   inputs (last wins); one point = flat. Point: natural cubic spline (tridiagonal second
   derivatives); pencil: linear; flat beyond the end points. Channel then composite. PSD `curv`.
4. Exposure: exposure -20..20, offset -0.5..0.5, gamma 0.1..9.99 (1). Decode sRGB, `* 2^e`,
   `+ offset`, signed `pow(v, 1/gamma)`, encode, clamp. Table. PSD `expA`.
5. Vibrance: vibrance, saturation -100..100. HSL; skip pixels with s = 0 when both are >= 0.
   `s1 = sat(s, saturation)`; `w = (1 - s1) * skin(h)`, skin = 1 outside 40 degrees of hue 25, falling
   to 0.5 at 25; `s2 = sat(s1, vibrance * w)`. PSD `vibA`.
6. Hue/Saturation: master hue -180..180, saturation and lightness -100..100; six ranges with bands
   [a, b, c, d] in degrees (reds 315,345,15,45, then +60 per range). Weight 1 inside b..c, linear
   ramps a..b and c..d, measured mod 360 from a. Deltas = master + sum(range * weight); `h + dh`,
   `sat(s, ds)`, `light(l, dl)`. Colorize (hue 0, sat 25, light 0): `hsl(H, S/100, light(l, L))`.
   PSD `hue2` (colorize read from the master record's flag bits).
7. Color Balance: shadows/midtones/highlights x cyan-red, magenta-green, yellow-blue -100..100,
   preserve luminosity on. Per channel value v: `ws = clamp((v - 0.333)/-0.25 + 0.5) * 0.7`,
   `wm = clamp((v - 0.333)/0.25 + 0.5) * clamp((v - 0.667)/-0.25 + 0.5) * 0.7`,
   `wh = clamp((v - 0.667)/0.25 + 0.5) * 0.7`; `v + sum(amount/100 * w)`. Preserve: SetLum to the
   original Lum. PSD `blnc`.
8. Black & White: reds 40, yellows 60, greens 40, cyans 60, blues 20, magentas 80 (-200..300), tint
   off, tint color (206, 185, 155). `gray = min + (max - mid) * w_primary + (mid - min) * w_secondary`
   (primary = family of the max channel, secondary = the max+mid mix); tint: `hsl(tintH, tintS, gray)`.
   PSD `blwh`.
9. Photo Filter: 20 presets plus custom, RGB: warming 85 236,138,0 (default); warming LBA 250,150,0;
   warming 81 235,177,19; cooling 80 0,109,255; cooling LBB 0,93,255; cooling 82 0,181,255; red
   234,26,26; orange 243,132,20; yellow 242,232,26; green 26,242,26; cyan 26,242,242; blue 29,82,234;
   violet 154,26,242; magenta 242,26,242; sepia 172,122,51; deep red 255,0,0; deep blue 0,51,153;
   deep emerald 0,153,51; deep yellow 255,204,0; underwater 0,194,177. Density 0..100 (25), preserve
   luminosity on.
   `v(1 - d + d * color)`; preserve: SetLum. PSD `phfl` (v2 RGB, v3 Lab).
10. Channel Mixer: per output R, G, B three weights and a constant (UI -200..200 %), monochrome off,
    gray row 40/40/20 %. `out_i = const_i + sum_j w_ij in_j`; monochrome uses the gray row for all.
    PSD `mixr`.
11. Color Lookup: 1D or 3D table from `.cube` (title, 1D/3D size, domain min/max) or `.3dl` (node
    count = cube root, scale from the max value: 1, 255, 1023, 4095 or 65535); interpolation
    tetrahedral (default) or trilinear; dither off. Index `clamp((v - dmin)/(dmax - dmin)) * (n - 1)`;
    dither adds `(hash - 0.5)/(n - 1)`. Table in a blob (D2), at most 16 MB. Parse errors name the
    line. PSD `clrL` (embedded table data read and written).
12. Invert: `1 - x`. PSD `nvrt`.
13. Posterize: levels 2..255 (4). `round(x(n - 1))/(n - 1)`. PSD `post`.
14. Threshold: level 1..255 (128). Per channel `x*255 >= level ? 1 : 0` (no luminance step). PSD `thrs`.
15. Gradient Map: gradient (black to white), reverse, dither. `t = 0.3R + 0.59G + 0.11B`, optional
    dither `+-0.5/4095`, linear interpolation between neighbouring entries of a 4096-entry table
    from `gradient.rs`, write RGB (table alpha forced to 1). Table: stop positions clamped to 0..1
    and sorted, flat outside the end stops; each segment uses its left stop's midpoint `m` (clamped
    0.001..0.999, default 0.5) as `s^(log 0.5 / log m)`; reverse mirrors positions and midpoints;
    interpolation `classic` (default) mixes the stored sRGB values, `linear` mixes decoded linear
    sRGB and re-encodes, `perceptual` mixes in OKLab. There is no smoothness parameter. The dialog edits a two-stop ramp; multi-stop gradients come
    from the gradient presets. PSD `grdm`.
16. Selective Color: mode relative (default) or absolute; families reds..magentas, whites,
    neutrals, blacks, each C, M, Y, K -100..100 %. Primary families weigh `max - mid`, secondary
    `mid - min`; whites `max(0, 2min - 1)`, blacks `max(0, 1 - 2max)`, neutrals `1 - whites - blacks`.
    `K = 1 - max`, `C = 1 - r - K` (M, Y alike); relative `X += X * adj * w`, absolute
    `X += adj * w`; clamp; `r = 1 - C - K`. PSD `selc`.
17. Shadows/Highlights (destructive): shadows amount 35, tone 50, radius 30; highlights amount 0,
    tone 50, radius 30; color correction 20; midtone contrast 0; black/white clip 0.01 % (0..50);
    radius 0..2500 px on a log slider. Algorithm: gap.
18. HDR Toning (destructive): method local adaptation, exposure and gamma, highlight compression,
    equalize histogram; radius 16 (1..500), strength 0.5, detail 30 (-100..300), shadow, highlight,
    exposure 0, gamma 1, vibrance 20, saturation 20. Algorithm: gap.
19. Desaturate: `r = g = b = (max + min)/2`.
20. Match Color: luminance 0..200 (100), color intensity 0..200 (100), fade 0..100, neutralize. Per
    channel mean and deviation from the histogram; target = own means (neutralize: mean of the
    channel means); `scale = 1 + (srcStd/std - 1) * intensity`; `m' = mean + (target - mean) *
    luminance`; `out = m' + (x - mean) * scale`; fade toward x. No source-image picker.
21. Replace Color: target color white, fuzziness 0..200 (40), localized off, range 0..100 (0), hue,
    saturation, lightness deltas. HSB distance `d = sqrt((dh/180)^2 min(s1, s2) + ds^2 + db^2)`,
    `radius = fuzz/200` (localized `fuzz(1 - range/200)/200`), `w = clamp(1 - d/radius)`; apply the
    deltas times w in HSL.
22. Equalize: one table from the luminosity histogram CDF, `(cdf(x) - cdf0)/(1 - cdf0)`, cdf0 = first
    non-empty bin.
23-25. Auto Tone / Contrast / Color: clip 0.1 % both ends, targets 0/128/255. Contrast: one composite
    Levels from luminosity percentiles; Tone: per-channel Levels from per-channel percentiles; Color:
    as Tone plus per-channel gamma `log(normMedian)/log(target/255)` clamped 0.01..9.99. Run as Levels.

**Where computed.** `engine/src/adjust.rs` (new): params validation, compile to the `Adjust` payload,
CPU kernels, destructive apply and the `.cube`/`.3dl` parsers; the WGSL path implements the same
opcodes. **Destructive flow.** Needs a pixel layer (or a smart object, section 7). Dialog with live preview
(debounce 100 ms, curves 50 ms); Cancel drops the preview; OK applies once. Kinds without a dialog
apply at once. Apply works on color channels in 64-row strips, alpha untouched; 8/16-bit results
round `clamp(v) * max`. Histogram kinds build the histogram over the selection region first.
(D12) With a selection the result is mixed by selection coverage, as M2 fill does. Undo label: the
menu label without ellipsis. Color Lookup first opens a file picker (`.cube`, `.3dl`) (D9).

**Adjustment layers.** Layer > New Adjustment Layer (16 kinds, separator after color lookup) and
the Adjustments panel (16 buttons in rows of 5, 6, 5, plus a fill layer row: solid with the
foreground color, gradient black to white, pattern). Creating one opens the Properties panel on it.
Properties edits params live on the compositor (one undo step per committed edit). Default name =
the kind's name. PSD: import keeps the parsed params instead of flattening (drops the
`adjustment layers were imported as pixels` warning); unknown library types become invert with a
warning (reference); export writes the same keys back.

## 4. Fill layers

Layer > New Fill Layer > Solid Color / Gradient / Pattern (dialogs), Layer > Layer Content Options
(reopens the dialog of the selected fill layer; refuses other kinds), Layer > Rasterize > Fill
Content. Double click on a Patterns or Gradients panel swatch adds a fill layer (undo "Pattern Fill",
"Gradient Fill"; a panel gradient fill takes style, reverse and dither from the gradient tool).
- Solid: color, starting at the foreground color (non-RGB foreground falls back to black).
- Gradient: style linear/radial/angle/reflected/diamond (linear), angle 90, scale 10..150 % (100),
  reverse off, dither off, align with layer on, offset (0,0). The dialog does not choose the
  gradient: it uses the gradient overlay default gradient (gap B7).
- Pattern: pattern (first available), scale 1..1000 % (100), angle 0 (clockwise), link with layer on.
Creation: names "Color Fill", "Gradient Fill", "Pattern Fill"; inserted above the active layer,
becomes the only selected layer, gets a mask revealing the selection (or all), then the selection is
dropped. Edit replaces `content` on every selected fill layer. Rendering: gradient geometry relative to
the document bounds; pattern tiles `patterns[id]` (transparent when
unknown). Rasterize renders the document bounds into pixels and keeps the layer id. Undo labels: menu
label (gap B7). PSD: `vectorFill` as SoCo / GdFl / PtFl, both directions.

## 5. Layer styles and blending options

**Model.** `Style { enabled, scale 0.01..10, drop_shadows[], inner_shadows[], color_overlays[],
gradient_overlays[], pattern_overlays[], strokes[], outer_glow, inner_glow, bevel, contour, texture,
satin }`. Each effect has `enabled` and `present`; it renders only when both are true. Lists hold up
to 10; the dialog adds instances for stroke, inner shadow, color and gradient overlay and drop shadow;
pattern overlay stays single in the dialog. Units: opacity 0..1, px in document px, angles in degrees.

**Defaults** (dialog ranges in brackets):
- Drop / inner shadow: multiply, 0.75, black, global light on, angle 120, distance 5 [0..250],
  spread/choke 0 [0..100 %], size 5 [0..250], contour linear, anti-alias off, noise 0; drop only:
  layer knocks out on.
- Outer / inner glow: screen, 0.75, color (255, 255, 190) or gradient, technique softer | precise,
  spread/choke 0, size 5, range 0.5, jitter 0, noise 0, contour linear; inner only: source edge | center.
- Bevel & emboss: inner bevel (outer, inner, emboss, pillow, stroke emboss), smooth (chisel hard,
  chisel soft), depth 1 [1..1000 %], up | down, size 5, soften 0 [0..16], global light on, angle 120,
  altitude 30 [0..90], gloss contour linear, highlight screen white 0.75, shadow multiply black 0.75.
  Contour sub: linear, anti-alias, range 1. Texture sub: pattern, scale 1 [1..1000 %], depth 1
  [-1000..1000 %], invert off, link with layer on, offset (0,0).
- Satin: multiply, 0.5, black, angle 19, distance 11, size 14, contour linear, invert on; no global light.
- Color overlay: normal, 1, 50 % gray. Gradient overlay: normal, 1, black to white, method classic
  (perceptual, linear), style linear (5 styles), angle 90, scale 1 [10..150 %], reverse, dither,
  align with layer on, offset. Pattern overlay: normal, 1, pattern, scale 1 [1..1000 %], angle 0, link.
- Stroke: size 3, position outside (inside, center), normal, 1, overprint off, fill solid black,
  gradient (overlay params) or pattern.
Contours: 18 named presets as curve points (sawtooth and steps in pencil mode), turned into a
1025-entry table by the curves spline of section 3; lookup interpolates; anti-alias off quantizes to 1/255.

**Primitives** (`engine/src/styles.rs`, new). Shape = layer alpha after the masks (the layer rect
when "transparency shapes layer" is off). Exact Euclidean distance transform at threshold 0.5,
minus 0.5 px, clamped >= 0: inside, outside and signed (`-inside` / `+outside`). Gaussian: sigma =
size/3 (`gaussian_kernel` in selection.rs) up to size 12, above that 3 box passes; clamp edges. Box
blur twice = tent. Spread: `max(v, clamp(r + 1 - outsideDist))`. Offset for angle A and distance d:
`dx = -d cos A`, `dy = d sin A`, bilinear for fractions. Contour: `LUT(clamp(v / max(0.01, range)))`.
Noise: `v *= 1 - noise * hash(x, y, seed)`, fixed seeds per effect (drop 3, inner shadow 17, outer
glow 29, inner glow 41). Every px parameter is multiplied by `style.scale`.

**Effects.**
- Shadows: angle = global when enabled. Source = shape (drop) or 1 - shape (inner); offset; spread
  `size * spread`; blur with `size - spreadPx`; inner: `* shape`; contour; noise; drop with knock
  out: `* (1 - shape)`; colorize.
- Glows: softer edge = spread then box blur twice with radius `(size - spreadPx)/2`; precise edge =
  `clamp((size - dist)/max(1e-6, size - spreadPx))`; inner center = `clamp(insideDist / (size(1 -
  min(0.99, choke))))` (softer adds a Gaussian of half that). Outer `* (1 - shape)`, inner `* shape`;
  contour with range; noise. Gradient glow: color = gradient(v + jitter), alpha = v * gradient alpha.
- Satin: `G = Gaussian(shape, size)`; `|shift(G, +off) - shift(G, -off)|`; contour; invert; `* shape`.
- Overlays: color = constant; gradient: box = layer bounds (aligned) or document, center = box
  center + offset * half size, length `(|w cos A| + |h sin A|) * scale`, t per style as in M2's
  gradient tool, midpoint exponent `log 0.5 / log m`, dither +-0.5/255; pattern: rotate, scale,
  nearest sampling, tiled, origin at the layer bounds + offset when linked. Alpha `* shape`.
- Stroke: band outside [0, size], inside [-size, 0], center [-size/2, size/2]; coverage
  `clamp(s - lo + 0.5) * clamp(hi - s + 0.5)`; without overprint the content alpha is multiplied by
  `1 - coverage * opacity` first.
- Bevel & emboss: height field H (smooth: shape box-blurred twice with radius s/2, s = max(0.5, size);
  pillow smooth: Gaussian of a signed profile; chisel: from `p = clamp(inside/s)`, `m =
  clamp(outside/s)` per style, soft chisel adds Gaussian(max(1, s/3))); texture adds `(gray - 0.5) *
  depth * (invert ? -1 : 1)`; soften blurs. Light `(cos A cos h, -sin A cos h, sin h)`. Central
  differences times `s * depth`, direction down flips the xy term, `I = (-(gx Lx + gy Ly) + Lz) /
  sqrt(1 + gx^2 + gy^2)`; shade `(I - Lz)/(1 - Lz)` above Lz, `(I - Lz)/Lz` below; gloss contour
  `2 LUT((c + 1)/2) - 1`; positive = highlight, negative = shadow. Contour sub multiplies by
  `LUT(1 - profile)`. Restrict: inner `* shape`, stroke emboss `* band`, outer `* (1 - shape)`.

**Order on one layer.** (1) masks multiply content alpha, shape taken after; (2) behind planes: drop
shadows in list order, then outer glow; (3) onto content: pattern, gradient, color overlays; (4) fill
opacity on the content (alpha, except color burn and linear burn pull color toward white, vivid,
linear light and hard mix toward 0.5); (5) satin, inner glow, inner shadows, bevel shadow then
highlight, strokes; (6) blend interior effects as group = clamp content alpha to the shape alpha;
(7) mask hides effects multiplies the behind planes by the mask. Composite: knockout, then behind
planes at effect opacity * layer opacity in their modes, then content with the layer mode, opacity
and blend-if (blend-if never touches behind planes). A styled clip base renders base plus clipped
layers first, then its style on that result with fill 1. Groups use the same path. Planes render per
256 tile with padding = the style's reach (bevel `1.5 size + soften`, other effects distance + size),
cached per layer keyed by shape version + style JSON (not cached when noise or jitter > 0).
Engine path (`emit_styled` in doc.rs): the padded region is read from the level-L content and mask
tiles (level 0 reads stored tiles anywhere on the grid, so off-canvas pixels cast effects; level L
reads pyramid tiles inside the document); a clip base or group is composited on the CPU from
per-tile sub-programs first (the clip base with its own fill and mask, then style fill 1; a styled
pass-through group is treated as isolated). The centre 256 x 256 of each plane is a straight RGBA
payload tile keyed by a mix of style, blending, fill, mode, input tile keys, bounds, global light,
patterns, level and tile. Level L > 0 renders on level-L tiles with every px parameter (and the
bounds box) scaled by 2^-L: approximate (patterns and noise do not scale), level 0 is exact. Bounds
(tight pixel bounds; the document for fills and groups) are read only when an effect uses them.

**Blending options.** Blend-if per channel gray, R, G, B with source and destination black/white
split pairs 0..255 (outer <= inner). Ramp 0 below black outer, up to black inner, 1 between, down to
white outer at white inner, 0 above; weight = product over configured channels, gray = Lum. Also
weights adjustment layers. Channels R/G/B checkboxes (stored), knockout none/shallow/deep, blend
interior as group off, blend clipped as group on, transparency shapes layer on, layer/vector mask
hides effects off, fill opacity 0..100.

**UI.** Layer > Layer Style: Blending Options, the ten effects, Copy/Paste/Clear Layer Style, Global
Light, Create Layer, Hide All Effects, Scale Effects. Dialog about 820x520: left list (Styles,
Blending Options, Bevel & Emboss with Contour and Texture rows, Stroke, Inner Shadow, Inner Glow,
Satin, Color Overlay, Gradient Overlay, Pattern Overlay, Outer Glow, Drop Shadow), checkbox per
effect, instance count, "+" and reorder/delete for multi kinds; right column OK, Cancel, New Style,
Preview, a sample swatch and Effects On. Make Default / Reset to Default per effect (stored in
settings). Canvas preview debounced 70 ms. Changing the angle with global light on changes the
document light. Refused on the background layer and fully locked layers. Global Light dialog: angle
(mod 360), altitude 0..90. Copy/paste: deep copy of the style (paste to all selected layers). Scale
Effects 1..1000 % sets `scale`. Hide All Effects toggles `enabled` on every styled layer. Create
Layer: each behind plane becomes its own layer below (name "<layer>'s <effect>", its mode and
opacity), the content with interior effects baked stays; style, fill and masks are removed. Layers
panel: fx badge (dimmed when off) opens the dialog; drag moves effects, Alt-drag copies.
Undo labels: dialog OK "Layer Style"; menu commands their label.

**PSD.** `lfx2` (or `lmfx` when a list has more than one instance) through ag-psd `effects`: scale,
master switch, all ten effects, multi lists, contours, patterns in `Patt`. Blending: fill opacity,
blend clipped/interior, transparency shapes, knockout (deep written as shallow, with a warning),
channel restrictions, blend ranges. Global light: image resources 1037/1049 (read default 120/30).
Mask-hides-effects is not written to PSD (reference); the manifest keeps it.

## 6. Smart objects

Layer > Smart Objects: Convert to Smart Object, New Smart Object via Copy, Edit Contents, Replace
Contents, Export Contents, Convert to Linked, Convert to Embedded, Relink to File, Update (All)
Modified Content, Stack Mode (store only, D11), Rasterize. File > Place Embedded / Place Linked.
Layer > Rasterize > Smart Object. Free Transform and Warp on a smart object edit its placement.

**Model.** `link = embedded { id } | linked { name, handle }` (D7); `source` = blob with the source
file bytes (D5) plus flattened source tiles; `source_size`; `transform` = projective 3x3 from source
px to document (affine for plain placement); `warp` = the M2 mesh; `filters` (section 7);
`stack_mask`, `stack_mode`. The cache is always regenerated from the source: flatten, map through
transform (resample.rs: bicubic a = -0.5 default, box pyramid when minifying by 2 or more) or warp
(warp.rs). Output over 1e8 px refuses the op. Cache bounds grow by the smart-filter footprint.

**Ops.** Convert: selected layers sharing the parent of the topmost; a new document at their union
bounds (min 1x1, same depth), layers moved in and offset; source written as described in D5; the
new layer takes the single layer's name (or a new group-style name), opacity 1, normal, the top
layer's blending, transform = translate to the bounds origin; inserted at the first original's index,
selected. Via Copy: deep copy above, new embedded id. Replace Contents: refuses empty input, keeps the
on-canvas corners for the new size, drops the filter cache. Rasterize: cache pixels, same id.
Free transform and warp on a smart object update `transform`/`warp` and re-render from the source (no
quality loss on repeated transforms). Edit Contents: D6. Undo labels: menu label (gap B10).

**PSD.** `placedLayer` (SoLd/PlLd: id, type, size, transform, non-affine transform, warp, filters)
and `linkedFiles` (lnk2/lnk3 data for embedded; linked get the file name and no data). Import maps
placed layers to `Smart` and drops the `imported as pixels` warning. A changed placement with filters
we cannot write refuses export with an error naming the filter.

## 7. Smart filters

Filter entry `{ id, filter, params, enabled, opacity, blend, mask? }`; the stack runs bottom to top in
array order (PSD order is reversed). Filter > Convert for Smart Filters (undo "Convert for Smart
Filters") wraps the layer through Convert to Smart Object. Applying a hosted command to a smart
object appends a filter instead of changing pixels. Layer > Smart Filter: Disable Smart Filters
(toggle: any enabled -> all off, else all on), Delete Filter Mask, Disable Filter Mask, Blending
Options (pick the filter, top one default; mode; opacity 0..100 %), Clear Smart Filters. One shared
stack mask plus optional per-filter masks; enable/disable and delete act on both. Each filter's
result is mixed onto its input by `opacity * mask` in its mode. The cache key includes the stack.
Two simplifications against the compositor: Dissolve on a filter mixes like Normal (no hash), and a
blur filter in a non-Normal mode uses a plain straight-color blend (no W3C `(1 - ab)` backdrop term).
(D8) Hosted in M3: the 16 layer adjustment kinds plus Gaussian blur. PSD: `placedLayer.filter` +
`filterEffectsMasks`; curves and brightness/contrast are PSD-writable, others refuse export by name.

## 8. Layer comps

Window > Layer Comps panel: list of comps (name + layer count); click applies (undo "Apply Layer
Comp"); a footer button adds "Layer Comp N" with the lowest free N (undo "New Layer Comp"). Capture
stores per layer (all layers, recursive): visible, x, y of the bounds origin, opacity, fill, blend,
a deep copy of the style; flags apply visibility / position / appearance default on; comment "".
Apply: visibility; appearance (fill clamped 0..1, pass through only on groups); position = translate by
the stored delta (skipped for empty bounds). A deleted comp refuses. File > Export > Layer Comps to
Files (gap B12). PSD: comps in image resources plus per-layer comp state (ag-psd `layerComps`, `comps`).

## 9. Reference quirks followed on purpose (owner may overrule each)

Q1 threshold per channel, not on luminance. Q2 adjustment weight ignores fill opacity. Q3 adjustments
never change alpha and skip a transparent backdrop. Q4 desaturate uses `(max + min)/2`, not Lum.
Q5 brightness/contrast mean fixed at 127. Q6 knockout deep = shallow, punching to transparent. Q7
channel checkboxes and blend clipped layers as group stored, not rendered. Q8 blend interior effects
as group is a clamp. Q9 bevel uses the height-field model of section 5. Q10 pattern overlay has no
"+" and only the first instance goes to PSD. Q11 mask hides effects is not written to PSD. Q12 the
gradient fill dialog does not choose the gradient; gradient map edits two stops only. Q13 fixed
hue/saturation bands in the dialog (PSD bands kept). Q14 no black & white presets or auto; no match
color source picker. Q15 minimal layer comps panel (D10). Q16 effect noise is a fixed hash.
