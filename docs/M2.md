# M2 Selection, transform, paint: spec

Milestone text and gates: `docs/PLAN.md` sections 4 and 5. Behavior and look follow the public
Photoshop user guide and the owner decisions below. Everything here is written in our own words;
option names are the common industry terms.

Status: draft for owner review. Items marked (D) need an owner decision before their batch starts.

## 0. Out of M2 scope (named so nobody builds them by accident)

- Object selection, select subject, focus area, select and mask: M7 (AI).
- Content-aware fill, content-aware crop fill, delete-and-fill: M5.
- Puppet warp, perspective warp, split warp: M5.
- Editable gradient (gradient fill layer), fill layers: M3. The M2 gradient tool paints pixels.
- Mixer brush, color replacement, background eraser, magic eraser, history brush, clone/pattern
  stamp, blur/sharpen/smudge, dodge/burn/sponge: M5.
- Color sampler, ruler, count, note: M9. Slice tools: M8. Artboard tool: M4.
- Out-of-gamut range in color range, gamut warning, CMYK picker model: M6.
- Multiple dock workspaces and floating panels: M9. M2 ships one fixed layout.

## 1. Workspace shell

Layout, left to right: tool bar, canvas (options bar above it), right dock. Own tokens and colors.

**Tool bar.** Vertical, one column (width about 48 px, buttons about 32x30 px, lucide icons).
Each slot holds a group of tools. The slot shows the last used tool of its group. A small corner
mark shows that a slot has more tools. Right click or a 350 ms long press opens a flyout with icon,
name and shortcut for each tool. Tooltip on hover shows name and shortcut. Arrow keys move focus.

M2 slots, top to bottom (letter = shortcut; Shift+letter cycles within the slot):

| Slot | Tools | Key |
|---|---|---|
| move | Move | V |
| marquee | Rectangular, Elliptical, Single Row, Single Column | M |
| lasso | Lasso, Polygonal Lasso, Magnetic Lasso | L |
| wand | Quick Selection, Magic Wand | W |
| crop | Crop, Perspective Crop | C |
| eyedropper | Eyedropper | I |
| brush | Brush, Pencil | B |
| eraser | Eraser | E |
| gradient | Gradient, Paint Bucket | G |
| hand | Hand | H |
| rotate | Rotate View | R |
| zoom | Zoom | Z |

Footer block: foreground and background chips (click opens the color picker), swap (X), reset to
black/white (D), quick mask toggle (Q). The existing hold-R rotate and drag-to-pan move onto the
Rotate View and Hand tools.

**Spring-loaded keys** (hold = temporary tool, release = back):
- Space: Hand. Ctrl+Space: Zoom in (click) or zoom to rectangle (drag). Ctrl+Alt+Space: zoom out.
- Ctrl: Move (not during an active transform).
- Alt in brush, pencil, gradient, bucket: Eyedropper. Alt in eraser: erase to history.
- Selection tools: Shift = add, Alt = subtract, Shift+Alt = intersect (pressed before the drag).
  During a drag: Shift constrains (square, circle, 45 degrees), Alt draws from the center.

**Options bar.** Height about 34 px, one row of controls for the active tool: number fields with
unit and scrub-drag on the label, selects, checkboxes, icon toggles, thin dividers between groups.
Each tool declares its options as a typed schema (id, kind, label, default, min, max, unit). The
bar and the persistence (localStorage per tool) are generic over that schema.

**Right dock.** Fixed column: Color + Swatches (tabs), Layers, History. Brush Settings opens as a
panel tab when a brush tool is active (F5 toggles it).

**Canvas cursors.** Crosshair for marquee, lasso cursors, wand, crop, eyedropper, bucket, move,
grab, zoom. Paint tools: brush outline circle (size at hardness), crosshair when Caps Lock is on,
standard pointer as a preference.

## 2. Color

- Foreground/background state lives in the UI store and persists. D resets, X swaps.
- **Color picker dialog.** Saturation/brightness field plus a vertical hue strip. Fields: H, S, B,
  R, G, B, L, a, b and hex. Current vs original preview. Web-safe warning icon (snap on click).
  Live preview while open; Cancel reverts.
- **Color panel.** Foreground/background wells (click selects which one is edited), the same
  field + hue strip, and the reset/swap buttons.
- **Swatches panel.** Grid. Default set: grey ramp plus 12 hues in light, base and dark rows.
  Click sets foreground, Alt+click sets background, "+" adds the foreground color, right click
  deletes (with undo inside the panel). Stored in IndexedDB. Import and export of ACO and ASE
  files (public formats; we add them because PLAN lists swatches
  as a Photoshop parity item).
- **Eyedropper.** Sample size: point, 3x3, 5x5, 11x11, 31x31, 51x51, 101x101 average. Sample:
  current layer or all layers (default all layers = composite). Click sets foreground, Alt+click
  sets background. While the button is held a sampling ring shows new color over old color.

## 3. Selection

**Model (engine).** The selection is one single-channel mask at document size and document depth,
stored as copy-on-write tiles in the same tile id space as layer masks. A missing tile means 0 or
full, like layer masks. The selection is part of the document: it is saved in the manifest,
restored by undo, and reselect keeps the last cleared mask. Analytic shapes (rectangle, ellipse)
rasterize at creation; there is no lazy shape form. Feather is a Gaussian blur of the mask.

(D1) Manifest v3 adds `selection: null | { tiles, default }`, `last_selection` and
`channels: [{ id, name, tiles, default }]` for saved selections. The reader keeps accepting v1 and
v2. This is a persistence change: independent review gate.

**Common options** for marquee and lasso: mode (new, add, subtract, intersect), feather 0-1000 px
(default 0), anti-alias (default on; rectangles are always hard).

**Marquee.** Style: normal, fixed ratio (W/H 0.01-1000, default 1:1), fixed size (1-30000 px,
default 100x100). Single row / single column: click makes a 1 px band across the canvas.
**Lasso** freehand (needs 3 points). **Polygonal lasso**: click adds a vertex, Backspace removes
the last one, double click / Enter / click on the start point closes, Esc cancels, Shift snaps the
segment to 45 degrees. Alt while drawing a freehand lasso switches to straight segments.
**Magnetic lasso**: width 1-256 px (default 10), contrast 1-100 % (default 10), frequency 0-100
(default 57), pen pressure changes width. Edge path via a live-wire shortest path on the gradient
magnitude inside the width band; anchors are placed automatically at the frequency spacing.
Click adds an anchor; closes like the polygonal lasso.

**Magic wand.** Tolerance 0-255 (default 32), anti-alias, contiguous (default on), sample all
layers (default off). Color distance: max channel difference, same as the paint bucket.
**Quick selection.** Brush size 1-5000 (default 30), mode default add, sample all layers,
auto-enhance (default on). Painting grows the selection by region growing from the brush samples
in a color model of the stroke, cut at strong edges; auto-enhance smooths the border. Alt paints
subtract.

**Select menu.** All (Ctrl+A), Deselect (Ctrl+D), Reselect (Ctrl+Shift+D), Inverse
(Ctrl+Shift+I), Color Range..., Modify > Border (1-200, default 10) / Smooth (radius 1-100,
default 2) / Expand (1-500, default 5) / Contract (1-500, default 5) / Feather (Shift+F6,
0.1-1000, default 1), each with "apply effect at canvas bounds" (default off). Grow and Similar
(tolerance 0-255, default 32; sample all layers). Transform Selection. Edit in Quick Mask Mode (Q).
Load Selection... and Save Selection....

**Color range dialog.** Select: sampled colors (default), reds, yellows, greens, cyans, blues,
magentas, highlights, midtones, shadows, skin tones. Fuzziness 0-200 (default 40), range 0-100 %
(default 100), localized color clusters (default off), invert. Eyedropper, add and subtract
eyedroppers on the canvas while the dialog is open. Grayscale preview of the result in the dialog.

**Save / load selection.** Save: into a new channel with a name, or combine into an existing
channel (replace, add, subtract, intersect). Load: channel, invert, and the four combine modes.
PSD: alpha channels read and written through ag-psd if it supports them (to verify in batch 3;
if not, they stay project-file only and PSD export drops them with a warning).

**Quick mask.** Q toggles. The selection shows as a 50 % red overlay on unselected areas. Paint
tools, fill, gradient and filters then edit the selection mask instead of the layer (black adds
mask, white removes it). Q again returns to marching ants. Double click on the Q button: options
(color indicates masked or selected areas, color, opacity).

**Display.** Marching ants: the 50 % contour of the mask, drawn as an animated black/white dash in
screen space over the canvas, recomputed per display level. Hidden with Ctrl+H.

## 4. Paint

**Stroke engine (engine, Rust).** A stroke is a list of input samples (x, y, pressure, tilt,
twist, time). The engine places dabs along the smoothed path at the spacing, rasterizes each dab
(round tip with hardness falloff, or a sampled tip, with angle, roundness and flips) into a
stroke buffer, and composites the stroke buffer onto the layer at the stroke opacity with the
blend mode. Flow limits the paint per dab; opacity caps the whole stroke (a stroke never exceeds
its opacity however often it overlaps itself). The selection and lock transparency clip the
result. Live preview: touched tiles update per frame through the existing tile path. Mouse input
counts as pressure 0.5 for dynamics and 1.0 for the pressure toggles off.

**Common options** (brush): size 1-5000 px (default 30), hardness 0-100 % (default 100), mode
(the 27 blend modes plus behind and clear), opacity, flow (default 100), smoothing 0-100 %
(default 10), airbrush (build-up while the pointer stands still), wet edges, pressure controls
size, pressure controls opacity.
**Pencil**: always aliased, no hardness and flow, auto erase (paints background color when the
stroke starts on a pixel that matches the foreground color).
**Eraser**: mode brush / pencil / block (block = fixed 16 screen px square), erase to history.
On a layer with locked transparency the eraser paints the background color.

**Shortcuts.** [ and ] size (steps scale with size), Shift+[ and Shift+] hardness 25 % steps.
Digits set opacity (1 = 10 %, 0 = 100 %, two digits typed within 0.8 s = exact value);
Shift+digits set flow. Shift+click draws a straight line from the last dab. Caps Lock toggles
the precise cursor. Ctrl+Alt+drag (right mouse) resizes (horizontal) and changes hardness
(vertical) with an on-canvas preview.

**Smoothing.** Pulled-string model: the paint point follows the pointer at a leash of 1.2 screen px
per smoothing percent (divided by zoom with adjust for zoom). Options: pulled string mode, catch up (finish the stroke to the pointer),
catch up on stroke end, adjust for zoom.

**Brush settings panel** (F5): tip shape (size, flip X/Y, angle -180..180, roundness 1-100 %,
hardness, spacing 1-1000 %), shape dynamics (size, angle and roundness jitter with a control
source and minimum; flip jitter), scattering (scatter 0-1000 %, both axes, count 1-16, count
jitter), texture (pattern, invert, scale, brightness, contrast, texture each tip, mode, depth,
minimum depth, depth jitter), dual brush (tip, mode, size, spacing, scatter, count), color
dynamics (fg/bg, hue, saturation, brightness jitter, purity, apply per tip), transfer (opacity and
flow jitter), brush pose (override tilt, rotation, pressure), noise, wet edges, build-up,
smoothing, protect texture. Control sources: off, fade (steps 1-9999), pen pressure, pen tilt,
rotation (twist), initial direction, direction. Live stroke preview at the bottom of the panel.

**Brush presets.** Brushes panel: grouped list of tips with size label, Load... (.abr) and Delete
Brush (context menu); no create or rename. Presets and patterns are stored in IndexedDB. **ABR import**: v1 and v2 (tips only,
default dynamics) and v6-v10 (sampled tips, patterns, dynamics descriptors). Brush hierarchy is
not read. Unknown blocks are skipped with a warning; a damaged file never crashes the import.

**Fill and stroke.** Edit > Fill (Shift+F5): contents foreground, background, color, black, 50 %
gray, white, pattern, history; mode; opacity; preserve transparency. Alt+Backspace fills with the
foreground color, Ctrl+Backspace with the background color (Shift adds preserve transparency).
Edit > Stroke: width 1-250 px (default 3), color, location inside / center / outside, mode,
opacity, preserve transparency. Both work on the selection, or on the whole layer if none.
Live preview while the dialog is open.

**Paint bucket.** Source foreground, background or pattern; mode; opacity; tolerance 0-255
(default 32); anti-alias; contiguous; all layers. Same flood fill as the magic wand.

**Gradient tool.** Style linear, radial, angle, reflected, diamond; opacity; mode; reverse; dither
(default on); transparency (default on); method perceptual (OKLab), linear (linear light),
classic (gamma-encoded sRGB). Drag sets start and end; Shift snaps to 45 degrees.
**Gradient editor.** Presets (includes live foreground-to-background and
foreground-to-transparent), type solid or noise. Solid: color stops and opacity stops on separate
tracks, midpoints between stops, location field, add by clicking the track, remove by dragging
off or Delete, minimum 2 stops per track, smoothness. Noise: roughness, color model RGB/HSB/Lab,
per-channel range, restrict colors, add transparency, randomize.

## 5. Transform

**Layer bounds (D2).** M1 limits layer pixels to the canvas. Moving, transforming and
non-destructive crop need pixels outside the canvas. Proposal: the tile grid of a layer becomes
sparse with signed tile coordinates; the compositor and PSD export use layer bounds; the canvas
only clips display and flatten. Engine change with a persistence effect (manifest v3, review gate).

**Move tool.** Drag moves the active layer or the selected pixels (a floating selection until
deselect or commit). Auto-select (default off in our build; Ctrl-click does it once) with target
layer or group. Arrow keys nudge 1 px, Shift+arrow 10 px. Alt+drag duplicates. Show transform
controls (option) turns the move tool into free transform on handle drag.

**Free transform** (Ctrl+T), also for the selection content and for Transform Selection (edits
only the mask outline). Handles: 8 box handles, a rotate zone outside the corners, a reference
point (default center; a 3x3 picker in the options bar). Drag rules:
- inside: move; outside: rotate (Shift: 15 degree steps).
- corner or edge: scale; proportional by default for pixel layers, Shift toggles; Alt scales
  around the reference point.
- Ctrl+corner: distort (free corner). Ctrl+edge: skew. Ctrl+Alt+Shift+corner: perspective.
Options bar: X, Y, W %, H %, link, angle, H skew, V skew, interpolation (nearest, bilinear,
bicubic; default bicubic), mode switch to warp, cancel and commit. Enter or double click inside
commits, Esc cancels. Ctrl+Z inside a session steps back one handle drag. Preview renders
bilinear on the GPU view; commit renders with the chosen interpolation in the engine.
Snapping during move and transform: to canvas edges and center, layer bounds and their centers,
with a 10 screen-pixel catch and a 6 screen-pixel hold radius.

**Edit > Transform** submenu: Again (Ctrl+Shift+T), Scale, Rotate, Skew, Distort, Perspective,
Warp, Rotate 180, Rotate 90 CW, Rotate 90 CCW, Flip Horizontal, Flip Vertical. The first six open
free transform locked to that operation.

**Warp.** A 4x4 control grid of one bicubic Bezier patch (the public Photoshop default grid),
handles for points and tangents, drag inside the patch to bend the surface. Presets: none, arc,
arc lower, arc upper, arch, bulge, shell lower, shell upper, flag, wave, fish, rise, fisheye,
inflate, squeeze, twist, with bend and horizontal/vertical distortion. Grid display options
3x3/4x4/5x5 are for view only.

## 6. Crop

**Crop tool.** Opens with a crop box on the full canvas. Ratio: free, original, 1:1, 4:5, 5:7,
2:3, 16:9, custom W x H (0-30000), plus W x H x resolution (resamples). Swap ratio button. Clear.
Straighten: draw a line; its angle to the nearest axis rotates the crop. Drag outside the box
rotates the crop. Overlay: none, thirds (default), grid, diagonal, triangle, golden ratio, golden
spiral; the outside area is shaded. Delete cropped pixels (default on; off keeps layer pixels
outside the canvas, needs D2). Enter, the commit button or double click commits; Esc cancels.
A crop that equals the canvas with angle 0 is a no-op without history entry. Dragging the box
larger than the canvas extends the canvas (transparent, or background color on a background layer).

**Perspective crop.** Four free corners (click four points or drag a rectangle, then move the
corners), a grid inside the quad. Commit maps the quad to a rectangle with a projective resample
of every layer; the size comes from the average side lengths unless W/H is set. A degenerate quad
(crossing or collinear) shows an error and does not commit.

**Image menu, crop related.** Crop (to the selection bounds), Trim (transparent pixels, top-left
color, bottom-right color; top/bottom/left/right), Reveal All (needs D2), Image Rotation (180,
90 CW, 90 CCW, arbitrary angle, flip canvas horizontal and vertical).
