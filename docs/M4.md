# M4 Type and vector: spec

Milestone text and gates: `docs/PLAN.md` sections 4 and 5. Behavior and look come from the reference
app (rules in PLAN.md section 0) and the public Photoshop user guide. Everything here is written in
our own words; option names are the common industry terms. Where the reference app differs from the
PLAN wording, the reference wins; the quirks we follow on purpose and the deviations we choose are
listed in section 13.

Status: accepted by the owner 27 September 2026 (all section 14 recommendations, D1-D17). Section 16 gaps need a reading before their batch.

## 0. Out of M4 scope (named so nobody builds them by accident)

- Spell check, Find and Replace Text: edit area, not in the M4 line (PLAN section 1 lists them under
  edit). The Type menu ships without them.
- East Asian and Middle Eastern composers as separate engines: the Language Options radio and the
  composer flag are stored and round-tripped; layout uses the one composer of section 9. Tsume is
  stored and applied as a spacing reduction only (section 9).
- Text on a path and text in a shape as creation tools: render and round-trip only (D8).
- Line arrowheads (D7).
- Frames ("Frame from Layers"), slices, the ruler measurement tool, the count and note tools: M9.
- Artboards to Files / to PDF, export as, generate image assets: M8 (PLAN). M4 only models artboards.
- Layer > Align and Distribute of layers: not in any milestone line yet; owner to place it. M4 B8
  can host it next to path component alignment if the owner says so.
- Freeform pen with pen pressure width: no pressure path width; the magnetic option uses the M2
  livewire (section 4).
- Font embedding in project files or PSD (D4). Desktop font enumeration (Tauri): later, PLAN "Optional".

## 1. Document model and format (engine)

**Node kinds.** `Kind` in `engine/src/doc.rs` (today Pixel, Group, Adjustment, Fill, Smart) gains:
- `Shape { path, live, fill, stroke }`: no stored pixels. `path` is a `VectorPath` (section 2), in
  document px. `live: Option<Live>` is the parametric origin (`rectangle`, `roundedRectangle`,
  `ellipse`, `triangle`, `polygon`, `line`, `custom`) with `bounds` and per-type fields (four
  corner radii TL, TR, BL, BR; polygon `sides` 3..100, `star_inset` 0..0.99). `fill:
  Option<FillContent>` reuses the M3 fill content (solid, gradient, pattern); `None` = no fill.
  `stroke: Option<Stroke { enabled, width, align inside|center|outside, cap butt|round|square,
  join miter|round|bevel, miter_limit, dash: Vec<f64> (px), dash_offset, content: FillContent,
  opacity, blend }>`.
- `Text(TextData)`: `text` (UTF-16 indexing as in the UI; paragraph separator `\n`), `runs[]` and
  `paragraphs[]` as length-prefixed spans over `text`, `shape` = `point | paragraph { box } | onPath
  { path, start, end, flip } | inShape { path }`, `orientation` horizontal | vertical, `transform`
  (2x3 affine, text space to document px), `warp: Option<TextWarp>` (section 9), `anti_alias`
  per run, and `cache: Option<Tiles>` (rendered or imported pixels, D5).
Every `Node` gains `vector_mask: Option<VectorMask { path, enabled, linked, inverted, density 0..1,
feather px }>`, independent of `kind` (a pixel, fill, smart, shape or text layer can carry one next
to its raster mask). A `Group` gains `artboard: Option<Artboard { rect, background: none | white |
black | transparent | color, preset_name, guide_ids }>` (D14). The document gains `resolution` (ppi,
f64, D13), `paths: Vec<SavedPath { id, name, path, work }>` (at most one `work`), `guides:
Vec<Guide { id, axis x|y, pos (document px, f64) }>`, `grid { spacing_x, spacing_y }` (px),
`guides_locked` and `artboards_locked`.

Rules: paint, fill, pixel filters and adjustments on a shape or text layer refuse with an error
naming the kind ("... must be rasterized ..."), as M3 does for smart objects. Move and free
transform work on shape and text layers (text: `transform` is updated, the layer stays text; shape:
path points are mapped, `live` survives only an axis-aligned scale plus translate, Q6). Shape and
text layers accept layer styles; their style shape is the rendered coverage.

(D1) **Manifest v5 in one bump.** All M4 fields land in B1 so the format changes once: kinds
`shape`, `text`; per node `vector_mask`; per group `artboard`; document `resolution`, `paths`,
`guides`, `grid`, locks. Paths are JSON arrays of points `[x, y, inX, inY, outX, outY]` with absolute
handle coordinates (reference model), per subpath `closed` and `op`, per path `fill_rule`. Text runs
and paragraphs are typed JSON; unknown keys from a newer file are an error. The text cache is tiles
in the tile id space (M3 D2), so the `.pbaer` container and autosave keep their layout. The reader
keeps accepting v1 to v4 (`MANIFEST_VERSION` in doc.rs is 4 today). Persistence change: independent
review gate.

(D16) **No program version bump.** Shape, text and vector masks reach the draw program through the
existing payload kinds (RGBA8 tile for shape/text content, mask8 tile for the combined mask); the
program stays at version 2. If B3 finds it needs a new op, the bump to version 3 happens in B3 only,
under its review gate.

## 2. Vector geometry (engine)

`engine/src/path.rs` (new), pure functions, f64 in document px:
- **Model.** `VectorPath { fill_rule nonzero|evenodd, subpaths: [{ closed, op combine|subtract|
  intersect|exclude, points }] }`. A segment from P to Q is the cubic (P, P.out, Q.in, Q); equal
  handle and anchor = straight segment.
- **Flatten.** Adaptive subdivision until the chord distance is under 0.05 px (`FLATNESS`).
- **Fill coverage.** Exact area coverage per pixel (signed-area accumulation per scanline, the
  common font-rasterizer method), fill rule per path. Subpaths combine in list order by their op on
  coverage values: combine `a + b - ab`, subtract `a(1 - b)`, intersect `ab`, exclude `a + b - 2ab`
  (the first subpath starts from 0 with combine). Output: mask8 tiles, `round(c * 255)`.
- **Stroke outline.** Stroke to a closed outline, then fill nonzero. Align: center = +-w/2; inside
  and outside on closed subpaths = the full 2w stroke intersected with (inside) or minus (outside) the
  fill; open subpaths always center. Caps butt/round/square; joins miter (limit `miter_limit`, fall
  back to bevel), round, bevel. Dashes in px with offset, applied along the flattened arc length.
- **Boolean ops** (D10): unite, subtract front, intersect, exclude, merge components, on flattened
  polygons; result is corner anchors, fill rule nonzero.
- **Other.** Exact bounds (curve extrema), point-in-path with a px tolerance, nearest segment
  parameter (for add anchor), split at t (de Casteljau), affine map, and contour trace of a mask8
  selection (marching squares at 0.5) plus curve fit within a tolerance (Make Work Path).
- **Live shapes.** Generators: rectangle (four radii, each clamped to half the shorter side, arcs
  as cubics with kappa 0.5522847), ellipse (four cubics), triangle, polygon and star (`sides`,
  `star_inset`, first point at the top), line (a closed rectangle of the stroke weight along the
  segment), all clockwise from the top-left in screen space.

## 3. Compositor

- **Shape layer.** The engine renders per requested tile: fill content (M3 fill renderer: solid,
  gradient via gradient.rs, pattern via pattern.rs) multiplied by the path fill coverage, then the
  stroke plane (stroke content times stroke coverage, stroke opacity and blend over the fill). The
  result is a straight RGBA transient payload tile drawn by the ordinary `Draw` step, cached like M3
  fill tiles (key = path + fill + stroke JSON + level + tile). Level L > 0 renders the path scaled by
  2^-L (exact geometry, no pyramid of pixels).
- **Text layer.** `cache` tiles are drawn like pixel content. A missing cache is rendered by the
  typesetter (section 9) on demand and stored; any edit to text data drops it.
- **Vector mask.** Coverage of `vector_mask.path` (inverted when `inverted`), feathered by a Gaussian
  of `feather` (sigma rule: gap B3), then density: `m = 1 - density(1 - m)` (Photoshop user guide
  meaning of mask density). Disabled = 1. The combined mask is `raster x vector` and goes to the
  program as a mask8 payload tile. Linked masks move and transform with the layer; unlinked do not.
- **Artboard.** An artboard group is isolated; its children are clipped to `rect`; the background
  (white, black, color; none and transparent draw nothing) is drawn under the children inside
  `rect`. Pixels of children outside every artboard stay stored and are not drawn.
- **Styles.** Shape and text layers use the M3 styled path; their shape alpha is the rendered
  content alpha.

## 4. Paths, pen tools and the Paths panel

**Paths panel** (Window > Paths). Rows: thumbnail, name ("Work Path" in italics for the work path),
subpath count. Click selects the path (Properties target); Ctrl-click on a thumbnail loads it as a
selection (Shift adds, Alt subtracts, Shift+Alt intersects, as the selection tools). Row actions:
Save Path (work path only: becomes "Path N", lowest free N), Delete Path, double click renames.
Footer: Fill Path, Stroke Path, Load Path as Selection (selected, else work, else first path),
Make Work Path from Selection, Convert Path to Shape (foreground color fill), New Path. Undo labels:
"New Path", "Delete Path", "Save Path", "Rename Path", "Fill Path", "Stroke Path", "Make Selection",
"Make Work Path", "Convert Path to Shape".
- Fill Path: path coverage filled with the foreground color on the active pixel layer (M2 fill
  flow, blend normal, opacity 100 %). Stroke Path: the M2 brush stroked along the flattened path
  with the current brush tip, spacing and color (`engine/src/stroke.rs`), no pressure simulation.
- Make Selection: path coverage as the new selection, feather 0, anti-aliased, mode by modifiers.
- Make Work Path from Selection: dialog Tolerance (range and default: gap B5); replaces the work path.

**Editing target.** One path-edit op in the engine takes a role: `shape` (the layer's
`Shape.path`), `vectorMask` (the layer's mask path) or `document` (a `paths[]` entry). Pen and
selection tools resolve the target: a selected shape layer, else the selected layer's vector mask
when the mask thumbnail is active, else the selected Paths row, else a new work path.

**Tools** (slot P: Pen, Freeform Pen, Curvature Pen, Add Anchor Point, Delete Anchor Point, Convert
Point; slot A: Path Selection, Direct Selection). Held Ctrl/Cmd with a pen tool = Direct Selection;
held Ctrl/Cmd does not switch to Move while a path edit is open (reference).
- Pen: click adds a corner anchor, drag adds a smooth anchor with mirrored handles; click on the
  first anchor closes the subpath; Enter or Esc ends an open subpath; hovering a segment of the
  target path adds an anchor, hovering an anchor deletes it (auto add/delete); Alt-drag on a handle
  breaks the mirror. Exact mechanics: gap B6.
- Freeform Pen: freehand samples fitted with the section 2 curve fit (tolerance 2 px until gap B6
  says otherwise); Magnetic option routes through `engine/src/livewire.rs` as the M2 magnetic lasso.
- Curvature Pen: click adds smooth anchors whose handles are recomputed from the neighbours, double
  click adds a corner anchor (gap B6).
- Add / Delete / Convert Point: on the target path; Convert toggles smooth and corner (drag pulls
  new mirrored handles).
- Path Selection: selects whole subpaths (Shift adds), drag moves them, Alt-drag copies; Delete
  removes them. Direct Selection: selects anchors and handles, marquee select, drag moves, arrow
  keys nudge 1 px (Shift 10 px).
New subpaths drawn into a shape layer get the options bar path operation (combine by default).
Undo: one step per completed anchor gesture and per selection-tool drag (labels: gap B6).

**PSD.** Saved paths and the work path are image resources 2000-2997 and 1025, which ag-psd 31.0.2
does not model (D11).

## 5. Shape tools, live shapes and boolean ops

**Tools** (slot U): Rectangle, Ellipse, Triangle, Polygon (star through the star ratio), Line, Custom
Shape. Drag draws from corner to corner; Shift constrains to square/circle (line: 45 degree steps);
Alt draws from the center (rectangle, ellipse, polygon); a click without drag opens a size dialog
(gap B7). Options bar: mode Shape | Path, fill, stroke (width, style), path operation (new layer,
combine, subtract, intersect, exclude), and per tool: corner radius (rectangle), sides and star ratio
(polygon), weight (line), shape picker (custom). Shape mode creates a shape layer "Rectangle 1",
"Ellipse 1", ... (lowest free N per kind) above the active layer; with a shape layer selected and a
non-new path operation, the subpath is added to it instead. Path mode writes into the editing target
of section 4. Undo label: the tool name (gap B7).

**Live shapes.** Properties panel, Appearance section: Fill (M3 fill content picker, "no fill"), Stroke
(same, "no stroke" = `enabled` off, keeps the record; turning it on creates width 1, center, butt,
miter, limit 4, no dashes), Width 0..1000 px, Style solid | dashed (`[4w, 2w]`) | dotted (`[w,
1.5w]`, forces round cap, Q7; the shown style is derived from the pattern), Placement, Cap, Join.
Rectangle: four radius fields laid out TL, TR, BR, BL with a link toggle (linked writes all four);
max = half the shorter side. Triangle and polygon: one linked radius. Polygon: Sides 3..100 (5),
Star ratio 0..99 % (0). Line: no fill row. Undo labels: "Shape Fill", "Shape Stroke", "Stroke
Width", "Stroke Style", "Stroke Placement", "Stroke Cap", "Stroke Join", "Polygon Sides", "Polygon
Star Ratio", corner radius (gap B7).

**Boolean ops.** Layer > Combine Shapes: Unite Shapes, Subtract Front Shape, Intersect Shape Areas,
Exclude Overlapping Shapes, Merge Shape Components. Properties Pathfinder section: the first four as
buttons, enabled when more than one shape layer is selected or the one selected shape has more than
one subpath. Several layers: the topmost's fill and stroke win, the result replaces them at the
topmost's index. One layer: the op runs on its subpaths. Every boolean op drops `live` (Q6).

**Custom shapes.** Shapes panel (Window > Shapes): searchable grid of 34 px thumbnails; click arms
the Custom Shape tool with that shape. Load imports a `.csh` file through ag-psd `readCsh`
(measured: `dist/csh.d.ts` in ag-psd 31.0.2 returns `{ name, id, width, height, paths, ... }`);
duplicate ids get a suffix. The library lives in IndexedDB beside the M3 presets; starting set: a
small own-drawn set (gap B8 for the reference's defaults).

**PSD.** Import: `vectorFill` + `vectorMask` (+ `vectorStroke`, `vectorOrigination`) becomes a shape
layer (today psd.ts keeps its raster, "vector mask layers were imported as pixels"); `vectorMask`
alone on another kind becomes `vector_mask`. Knots: ag-psd `BezierKnot.points` (6 numbers,
preceding handle, anchor, leaving handle) to our absolute point; `linked` is kept as a smooth flag.
`BooleanOperation` combine|subtract|intersect|exclude maps 1:1 to `op`. `vectorStroke`: lineWidth,
alignment, cap, join, miterLimit, dash set (unit: gap B4), content, opacity, blend. Live shapes:
`keyOriginType` numeric map and `keyOriginRRectRadii` per corner (gap B4); `keyShapeInvalidated`
written true when `live` was dropped. Export writes all of these back.

## 6. Vector masks

Layer > Vector Mask: Reveal All, Hide All, Current Path (the selected path), Delete, Enable Vector
Mask (check), Link Vector Mask (check). Layer > Rasterize: Shape, Vector Mask, Type join the M3
entries (Fill Content, Smart Object). Rasterize Vector Mask multiplies the vector mask into the
raster mask (created if absent) and removes the vector mask. Layers panel: a second mask thumbnail
after the raster mask; click targets it for the path tools, Ctrl-click loads it as a selection.
Properties Vector Mask section: Density 0..100 % (100), Feather 0..1000 px step 0.1 (0), Enabled,
Linked, Inverted, Reset (enabled, linked, density 1, feather 0, not inverted). Undo labels: "Vector
Mask Density", "Vector Mask Feather", "Enable Vector Mask", menu labels for the menu items.
**PSD.** `vectorMask { invert, notLink, disable, fillStartsWithAllPixels, paths }`, layer
`vectorMaskDensity` and `vectorMaskFeather` (units: gap B4), both directions. `realMask` (combined
user and vector mask) becomes computable, so the corpus `realMask` skips can leave.

## 7. Copy SVG / CSS and shape attributes

Layers panel context menu on shape layers (and the Layer menu): Copy CSS, Copy SVG, Copy Shape
Attributes, Paste Shape Attributes. Clipboard text through `navigator.clipboard.writeText`.
- Copy SVG: one `<svg>` with `viewBox` = the layer bounds, one `<path>` per layer (`d` absolute,
  2 decimals, `fill-rule`), fill as a color or a `linearGradient`/`radialGradient`, stroke attributes
  (`stroke-width`, `-linecap`, `-linejoin`, `-miterlimit`, `-dasharray`); inside/outside stroke

- Copy CSS: `position`, `left`, `top`, `width`, `height`, `background` (color or gradient),

  non-rectangular paths add `clip-path: path(...)`.
The emitted field set follows the reference once gap B8 is read (D15); until then the lists above.
- Copy/Paste Shape Attributes: fill and stroke records onto every selected shape layer (undo
  "Paste Shape Attributes").

## 8. Fonts and missing fonts

**Sources** (D3): a bundled OFL set (loaded from the app, cached by the service worker, offline),
user-uploaded font files (TTF, OTF, TTC, at most 64 MB; WOFF/WOFF2 deferred: ttf-parser does not decode them; stored in OPFS
`fonts/`, index in IndexedDB), and on Chromium the Local Font Access API after a user gesture
(`queryLocalFonts`, blobs loaded on demand). The registry lists faces `{ family, style, weight,
italic, postscript, source }`. Font registry calls are app scope: they carry no document id and are
not refused when the document changes; layout and render calls are document calls (protocol rule of
the worker dispatcher).

**Family list.** Unique families sorted by locale compare; hidden: names starting with "." or "@"
and color-emoji families. Lookup by PostScript name as well (PSD stores PostScript names).

**Style matching** when the exact style is missing: weight from style words (thin 100, extra light
200, light 300, regular 400, medium 500, semibold/demi 600, bold 700, extra/ultra bold 800,
black/heavy 900) plus italic/oblique; nearest weight wins, an italic mismatch costs more than any
weight gap, Regular wins ties.

**Fallback.** Tool default font: the tool's font if it draws A-Z, a-z, 0-9, else the first family of
a fallback list that does (list: the bundled sans first, then common system families when present),
else any family. Per-run glyph fallback: characters the run font lacks take the first fallback face
that has them (per character); script probe lists for Korean, CJK and Arabic (the Arabic probe
requires U+067E).

**Missing fonts.** On open (and on window focus, since uploads and permissions change), every
(family, style) pair of all type layers is resolved; unresolved families are "missing". A layer
with a missing font keeps its cache and renders it (D5) until edited. Entering edit on such a layer
opens Resolve Missing Fonts scoped to it. Type > Replace All Missing Fonts: info "no missing fonts"
when none; else a dialog with the missing family (or count), Replace With family and style; applies
to every run using a missing face in all type layers (undo = menu label). Type > Resolve Missing
Fonts: one row per missing (family, style) with a replacement picker and a text preview;
auto-suggest takes the first family of the fallback list that draws the affected characters; OK
applies the substitution map (one undo step). Both dialogs add an "Upload font..." button (web build,
D3). Type > Update All Text Layers drops every text cache (relayout with current fonts).

## 9. Type model, layout and rendering

**Runs** (defaults): family "" (resolve default), style "Regular", size 12 pt (tool default 28),
tracking 0 (1/1000 em), leading auto (1.2 x size), color black, faux bold/italic off,
underline/strikethrough off, caps normal | all | small, baseline normal | super | sub, baseline
shift 0 pt, horizontal/vertical scale 1, anti-alias sharp, ligatures on, discretionary ligatures
off, kerning metrics, language "", no break off, tsume 0, `features` map (D6). **Paragraphs**:
alignment left | center | right | justify-left | justify-center | justify-right | justify-all,
indents left/right/first 0, space before/after 0 (pt), hyphenate off, rtl off, composer every-line,
justification word 80/100/133, letter 0/0/0, glyph 100/100/100 %, hyphenation (words longer than 5,
after first 2, before last 2, limit 2, zone 36 pt, capitalized on), roman hanging punctuation off.

**Units.** Lengths in pt, px = pt x resolution / 72. PSD engine values are px at 72: import
multiplies by 72 / resolution, export by resolution / 72.

**Layout** (`engine/src/typeset.rs`, new; library per D2): paragraphs split on `\n`; bidi per
paragraph (rtl forces RTL, else auto); script itemization (latin, greek, cyrillic, hebrew, arabic,
devanagari, thai, hangul, kana, han, common); per-run face with per-character fallback; shaping with
the run's features (liga, clig, calt on by default; dlig, salt, swsh, titl, ornm, smcp, onum, ordn,
frac per `features`); kerning metrics (optical and none: gap B10); tracking adds `tracking/1000 x
size` after every glyph; horizontal/vertical scale scale advances and outlines. Superscript and
subscript: size x 0.583, offset +0.333 em / -0.333 em; small caps size x 0.7 (unless the font has
smcp and the feature is on). Faux bold / italic amounts: gap B11.
Line breaking: UAX #14 opportunities, hyphenation candidates only when `hyphenate` and a pattern
set exists (D17). Composers: single-line = greedy first fit; every-line = total fit (minimum sum of
squared line slack, hyphen penalty). Point and on-path text default to single-line, paragraph text
to every-line unless the paragraph sets it. Point text: one line per paragraph. Paragraph text:
measure = box width - indents (first line minus first indent); lines stop when the next would pass
the box bottom, `overflow = true`, the rest is not drawn. Space before/after between paragraphs.
Justify variants justify every line but the last (justify-all: the last too) within the
word/letter/glyph ranges; the last line follows the named alignment. Tsume reduces the side
bearings of CJK glyphs by `tsume` x (advance - ink width) / 2 on each side.
**Vertical**: columns right to left, column pitch = leading; han, kana and hangul upright (vertical
advance, `vert` feature), other glyphs rotated 90 degrees clockwise.
**On path**: laid out as one line, glyphs placed along the first subpath by arc length from `start`,
rotated to the tangent, dropped past `end`; `flip` reverses direction. **In shape**: each baseline
intersects the closed path (fill rule honoured), text fills the spans top down, overflow past the
bottom.

**Rendering** (`engine/src/glyphs.rs`, new; closed B11 gaps from the reference): glyph outlines are
flattened in text px (flatness 0.05 px divided by the power of two at or above the transform's
largest scale) into closed corner-point polygons, warped, then mapped through `transform`; the layer
outline is one nonzero `VectorPath` of those polygons. Faux italic skews font units by x += y tan 12
degrees; faux bold moves every contour point (a curve's handles move with its end point) outward by
0.012 em along the normal of the chord between its neighbours and widens the advance by 0.024 em
(bold first, then italic). Underline and strikethrough: per run segment of a line, a rectangle at
baseline - position x px/em, thickness max(1 px, thickness x px/em), from the post/OS2 metrics
(fallback -0.1 em / 0.05 em and 0.25 em / 0.05 em); not drawn on path text. Polygons are grouped by
color (first appearance order); each group is filled (nonzero) and composited over the previous
ones. Anti-alias comes from the first run: none = binary coverage (pixel center inside); the others
take area coverage c and apply, where c > 0: smooth first blurs by a Gaussian of sigma 0.35 (radius
2); then c = c^gamma, c = (c - 0.5) x contrast + 0.5, c = c x (1 + darken), clamped 0..1, with
(gamma, contrast, darken) sharp (0.85, 1.35, 0), crisp (0.7, 1.75, 0.05), strong (0.55, 1.15,
0.16), smooth (1.1, 1, 0.02). The cache covers the outline bounds plus 1 px. The same outline
feeds Create Work Path (replaces the work path), Convert to Shape (replaces the type layer in place,
same name and layer settings, locks cleared, solid fill = first run color), the Type Mask tools and
hit testing (2 px tolerance).

**Warp text** (D9). Styles none, arc, arc lower, arc upper, arch, bulge, shell lower, shell upper,
flag, wave, fish, rise, fisheye, inflate, squeeze, twist; bend -100..100 % (50 when the dialog opens
on an unwarped layer), horizontal and vertical distortion -100..100 % (0), stored as fractions -1..1;
axis horizontal (the reference dialog has no axis choice; PSD `rotate` is read and kept). The warp
maps the flattened outline points of the whole layer through a function of the style over the
unwarped text bounds before filling (vector warp, text stays editable). Style none removes the warp.
Formulas (from the reference): bounds B = the unwarped layout bounds (line boxes; glyph boxes on a
path), u = (x - Bx) / Bw, v = (y - By) / Bh, X = 2u - 1, Y = 2v - 1; then Y *= 1 + H X, then
X *= 1 + V Y (H, V the distortions); A = -b Bh/2 (1 - X^2) (b the bend). dy: arc A; arc lower A v;
arc upper A (1 - v); arch A (0.5 + 0.5 v); bulge Y Bh/2 b (1 - X^2); shell lower A v with dx =
-b X Bw/2 0.3 v; shell upper A (1 - v) with dx = -b X Bw/2 0.3 (1 - v); flag -b Bh/2 sin(2 pi u);
wave flag x (1 - 2v); fish -Y Bh/2 b X^2; rise -b Bh/2 X. Fisheye: E = 1 + b (1 - min(1, hypot(X, Y))^2),
dx = X (E - 1) Bw/2, dy = Y (E - 1) Bh/2. Inflate: dx = X b (1 - Y^2) Bw/2, dy = Y b (1 - X^2) Bh/2;
squeeze the negation. Twist: rotate (X Bw/2, Y Bh/2) by b pi min(1, hypot(X, Y)), d = rotated - original.
Result (Bx + (X + 1) Bw/2 + dx, By + (Y + 1) Bh/2 + dy). Polygon edges are subdivided to at most
4 px first. Bend and both distortions 0, or empty bounds: no warp (and no subdivision).

**PSD** (ag-psd `text`): import maps `text`, `transform`, `orientation`, `antiAlias` (platform and
platformLCD to smooth, missing to smooth), `shapeType` point|box, `boxBounds`, `styleRuns` merged
over `style` (font.name PostScript name, fontSize, tracking, autoLeading/leading, fillColor, fauxBold,
fauxItalic, underline, strikethrough, fontCaps 1 small / 2 all, fontBaseline 1 super / 2 sub,
baselineShift, horizontal/verticalScale, ligatures, dLigatures, kerning/autoKerning, noBreak,
tsume), `paragraphStyleRuns` over `paragraphStyle` (justification, startIndent, endIndent,
firstLineIndent, spaceBefore, spaceAfter, autoHyphenate, everyLineComposer), `warp` (style, value to
bend, perspective to horizontal, perspectiveOther to vertical; scale: gap B12), `textPath` for
on-path/in-shape. The layer pixels become `cache` (D5); the raw ag-psd text object is kept (as
unknown data in the manifest) for lossless write-back. Export starts from the kept raw object and
overwrites the mapped fields; runs and paragraphs merge over the original at the same index only
while the count is unchanged, else they are written fresh; font.name = the PostScript name (not the
family, deviation); warp is written from our model (deviation). Drops the "text layers were imported
as pixels" warning.

## 10. Type tools, panels and the Type menu

**Tools** (slot T): Horizontal Type, Vertical Type, Horizontal Type Mask, Vertical Type Mask.
Options bar: orientation toggle, family, style, size (0.01..1296 pt, step 0.01, default 28),

## 12. Rulers, units, guides, grid, smart guides and snapping

**Units.** px, in, cm, mm, pt, pica, percent. With resolution r ppi: 1 in = r px, 1 cm = r/2.54,
1 mm = r/25.4, 1 pt = r/72, 1 pica = r/6; percent = of the document width (x) or height (y).
Edit > Preferences > Units & Rulers: ruler unit (default px), type unit (pt). Preferences are
app-wide (IndexedDB settings); resolution, guides and grid spacing are per document. Image > Image
Size shows and edits resolution (resample off = metadata only) (gap B16 for the New Document
default, D13).

**Rulers.** View > Rulers (Ctrl+R) toggles top and left rulers; origin at the document (or targeted
artboard) top-left; tick steps chosen from 1-2-5 series so labels are >= 50 screen px apart; a
pointer marker on both rulers; right click on a ruler picks the unit. Rotated views: rulers follow
the document axes of the unrotated view (gap B16).

**Guides.** Drag from a ruler creates a guide (top ruler: horizontal, left: vertical; Alt swaps);
drag with the Move tool moves it; drag back onto the ruler deletes it. View > Guides (Ctrl+;), Lock
Guides (Ctrl+Alt+;), Clear Guides, Clear Canvas Guides, Clear Selected Artboard Guides, New Guide
(orientation, position px 0..width/height, relative to the targeted artboard, Q10; "New Guide"), New
Guide Layout (columns 0..100 (3), column gutter 0..500 (20), rows 0..100 (0), row gutter 0..500 (20),
margin toggle off with top/left/bottom/right 0..2000, clear existing on; once per selected artboard
else the canvas; 0 skips an axis; "New Guide Layout"), New Guides From Shape (bounds edges and centers
of the selected shape: gap B16). Guide moves, creation and deletion are history steps. Guide color
and style: Preferences > Guides, Grid & Slices (gap B16).
**Grid.** View > Show > Grid (Ctrl+'), spacing per axis from the document (default 18 px, the PSD
writer default), subdivisions, color and style from preferences (gap B16). View > Show > Pixel Grid
at zoom >= 800 % (threshold: gap B16).

**Snapping.** View > Snap (Ctrl+Shift+;) master toggle, View > Snap To: Guides, Grid, Layers, Document
Bounds, Artboards, All, None (slices are M9). Stored in app settings. Targets per axis: min, center,
max of document bounds, visible layer bounds (shape layers use their path bounds, layers with a
vector mask the mask path bounds, others content bounds; the moving subtree excluded) and artboard
rects; guides add their position on their axis; grid snaps to the nearest grid line or subdivision
(gap B17: quantize or target list). Catch 6 screen px, release 10 screen px, both divided by zoom
(`app/src/shell/snapping.ts` today; Q12). Applies to: move, free transform, marquee, crop, shape
tools, pen anchors, type box drag, guide drag, artboard move. `snapTargets` in the worker (today
document bounds plus pixel/smart layer bounds) gains the categories. **Smart guides** (View > Show >
Smart Guides, default on): the alignment lines already drawn by `SelectionOverlay.ts` are shown only
when on; distance labels: gap B17.

**PSD.** Image resource 1032 (ag-psd `gridAndGuidesInformation`): guides as `{ location, direction }`
in px (ag-psd divides and multiplies by 32; measured in `imageResources.js`), grid spacing raw in
1/32 px (ag-psd writes 576 = 18 px when absent). Resolution: `resolutionInfo` (ppi; units inches and
cm kept for display). Artboard guides: `artboard.guideIndices` into the guide list.

## 13. Reference quirks followed on purpose, and deviations (owner may overrule each)

Q1 Esc commits a type edit; only the Cancel button cancels. Q2 committing empty text deletes the
layer. Q3 Windows and Windows LCD anti-alias equal smooth. Q4 Paste Lorem Ipsum without a session
replaces the text. Q5 character/paragraph styles are app-wide values without links (D12). Q6 a
transform with rotation or shear drops a live shape to a plain path; boolean ops always do. Q7 dotted
stroke forces a round cap, the style is derived from the dash pattern. Q8 triangle and polygon have
one linked corner radius. Q9 a new artboard goes to the right of the selected or last one. Q10 New
Guide positions are relative to the targeted artboard. Q11 New Guide Layout clears existing guides by
default and runs per selected artboard. Q12 snap catch 6 / release 10 screen px. Q13 the Type menu has
no shortcuts. Q14 the options bar offers three alignments, the Paragraph panel seven. Q15 glyphs
without a code point refuse insertion. Q16 imported type layers render their PSD pixels until edited
(D5). Q17 no creation tool for on-path/in-shape text (D8), no arrowheads (D7).

Deviations (the reference is not followed): PSD export writes the PostScript font name (the reference
writes the family); a warp set in the app is written to PSD (the reference drops it); the import warp
scale is converted (gap B12) instead of copied raw; Properties paragraph fields say pt (the reference
labels them px); Contextual Alternates is `calt` (the reference maps it to `clig`); OpenType features
are per run (D6); the Warp Text dialog does not add a warp axis (same as the reference, listed for
clarity).

## 14. Decisions (open, need the owner)

- (D1) Manifest v5 in one bump in B1 with the fields of section 1. Recommendation: yes (one
  persistence review, same pattern as M3 D1).
- (D2) Shaping and layout library. PLAN names HarfBuzz (harfbuzzjs); the reference uses opentype.js
  (GSUB single and ligature substitution plus kerning) and its own layout. Measured: none of
  harfbuzzjs, opentype.js, rustybuzz or ttf-parser is installed (`node_modules` holds ag-psd, react,
  lucide-react, vite, typescript; engine Cargo deps are wasm-bindgen, js-sys, serde). Recommendation:
  rustybuzz (a Rust port of HarfBuzz) with ttf-parser inside the engine WASM, plus own bidi, line
  breaking and composer: one module, deterministic `cargo test` goldens, complex scripts and the
  `vert` feature that opentype.js lacks, and it keeps PLAN's HarfBuzz intent. Fallback: harfbuzzjs in
  the worker. Licenses (cargo info, 27 Sep 2026): rustybuzz 0.20.1 MIT, ttf-parser 0.25.1 MIT OR Apache-2.0;
  any bidi/line-break crate and harfbuzzjs: to check before B9.
- (D3) Font source in the browser. Recommendation: all three, layered: a small bundled OFL set
  (candidates Noto Sans, Noto Serif, Noto Sans Mono; license to check per file, recorded next to it;
  also the test fonts), user uploads stored in OPFS with an IndexedDB index (every browser), and the
  Local Font Access API on Chromium after a user gesture. Desktop enumeration later with Tauri.
- (D4) Fonts are not embedded in `.pbaer` or PSD; layers store family, style and PostScript name.
  Recommendation: yes (font licenses often forbid embedding; D5 and the missing-font flow cover
  display).
- (D5) Imported type layers keep the PSD pixels as `cache` and render them until edited, a font is
  replaced or Update All Text Layers runs. Recommendation: yes (reference; the corpus stays exact while
  our line breaks differ, PLAN risk "PSD text fidelity").
- (D6) OpenType features: the reference keeps them as global app preferences. Recommendation: per run
  in `features` (the data model has the slot), the Type > OpenType items act on the selection; PSD
  writes `ligatures` and `dLigatures` only (the only feature fields in ag-psd `TextStyle`), others
  stay in the manifest.
- (D7) Line arrowheads: the reference has none (inventory sweep found no arrow fields). Recommendation:
  follow the reference, no arrowheads in M4; PSD lines keep whatever their path contains.
- (D8) Text on path / in shape: the reference renders them from PSD only. ag-psd marks `textPath` as
  read-only ("any changes will not be saved", measured in `psd.d.ts`). Recommendation: render and
  round-trip, no creation tool; an edited on-path/in-shape layer exports with a warning if gap B12
  shows ag-psd cannot write the path.
- (D9) Warp text formulas are unknown (not found in the reference inventory). Recommendation: one
  targeted read of the reference's warp style table first (gap B11); if unreadable, own formulas per
  style written into section 9 before B11, golden-tested against an independent Node script, and a
  visible difference to Photoshop accepted (imported warped text looks exact through D5).
- (D10) Boolean ops on flattened polygons with an own clipper (integer-scaled coordinates, no new
  dependency), result as corner anchors, curves not refit. Recommendation: yes for M4; the reference's
  algorithm is gap B8 (if it keeps curves, follow it). Alternative crate: i_overlay, license to check.
- (D11) Saved paths in PSD: ag-psd 31.0.2 has no handler for resources 2000-2997 and only a mock
  handler for 1025 (measured in `imageResources.js`). Recommendation: own small reader/writer of the
  public path-record format in `app/src/psd/`, reusing the vmsk knot layout; how to hook it into
  ag-psd's resource stream is gap B4.
- (D12) Character and paragraph styles: app-wide, by value (reference) or per document (Photoshop, in
  PSD). Recommendation: follow the reference.
- (D13) Document resolution: new field, from PSD `resolutionInfo`; new documents use the reference's
  New Document default once gap B16 reads it. Recommendation: 72 ppi if the gap stays open.
- (D14) Artboard = a top-level group with an `artboard` field (reference and PSD `artb`), isolated,
  clipping its children, drawing its background. Recommendation: yes; no canvas auto-expand in M4.
- (D15) Copy SVG / CSS output: follow the reference field set once gap B8 is read, else the lists of
  section 7. Recommendation: yes.
- (D16) No draw-program version bump (section 1). Recommendation: yes.
- (D17) Hyphenation needs pattern files whose licenses vary per language. Recommendation: store and
  round-trip the hyphenation settings, render without hyphenation in M4 unless the owner picks a
  pattern set with a checked license (English first).
